# 2api-plugin-gemini

基于 [gemini-business2api](https://github.com/yukkcat/gemini-business2api) 逆向协议转译的轻量 Cordis 2API 插件。

## 特性
- 深度提炼上游逆向交互协议：剔除独立 Vue 前端、Docker 编排与无头浏览器依赖。
- 支持全系列模型：`gemini-auto`、`gemini-2.5-pro`、`gemini-3.5-flash`、`gemini-3.1-pro-preview`、`gemini-imagen`、`gemini-veo`。
- 频次窗口额度监控与自动化 JWT 续期。
- 聚合接入统一控制台运营面板与遥测。
